# FIT SERVICE — инструкция по станциям

Рабочая инструкция для команды управляющей компании: заведение новой станции и закрытие станции.

Текущий сайт: https://fit-station-guide.tanchikpet.chatgpt.site

## Содержание

- Новая станция: 6 этапов — письмо, карточка в 1С, телефоны и посты, сайт, фид, георесурсы.
- Закрытие станции: 4 этапа — письмо, закрытие в 1С, сайт и фид, георесурсы.
- Ответственные, обязательные данные и результат каждого этапа.
- Сроки обновления ресурсов и ограничения проверки фида.

Сценарий открытия относится к городу, где уже есть действующие станции FIT SERVICE. Основа содержания — рабочий сценарий сентября 2026 года.

## Файлы

| Файл | Что менять |
| --- | --- |
| `index.html` | Общий заголовок, блоки сроков, роли участников |
| `app.js` | Тексты этапов в объекте `scenarios`, переходы между этапами |
| `styles.css` | Цвета, шрифт, размеры и адаптивная вёрстка |
| `assets/station.png` | Изображение станции в верхнем блоке |
| `assets/logo.svg` | Логотип FIT SERVICE |
| `assets/` | Иллюстрации этапов |

## Запуск

Сайт состоит из статических HTML, CSS и JavaScript. Установка зависимостей и сборка не нужны.

В корне репозитория выполните:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000 в браузере.

## Публикация

Эта копия содержит исходники опубликованного сайта. Изменения в этом репозитории сами по себе не обновляют текущий сайт: автоматическая синхронизация с хостингом не настроена.

Для размещения на другом статическом хостинге публикуйте корень репозитория с `index.html`, `styles.css`, `app.js` и каталогом `assets`.
